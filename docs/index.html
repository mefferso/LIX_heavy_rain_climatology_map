About this climatology

This map uses NOAA/NCEI nClimGrid-Daily precipitation analyses on the native ~5-km grid. Values represent grid-cell analyses rather than individual rain-gauge measurements.

Frequency is calculated as the average number of days per year meeting the selected threshold or rainfall range. Seasonal selections use the same annualized denominator, so the value answers “how many days in this season per year?”

The underlying analysis is interpolated from station observations. Individual pixels should not be interpreted as exact local rainfall maxima; broader spatial patterns are more robust.

Comparison views show the newer climatological period minus the older period at each grid point.

Observation support, when enabled, uses NOAA/NCEI nClimGrid-Daily-Auxiliary precipitation-observation counts within 30 miles of each grid point. It is an indicator of station-density support, not a formal confidence score.

Source: NOAA/NCEI nClimGrid-Daily and nClimGrid-Daily-Auxiliary.
