How this map is built

Methodology & caveats

The analysis counts nClimGrid-Daily grid-cell days meeting each precipitation threshold, then divides by the number of complete years in the selected climatological period. Seasonal views use the same method for the selected calendar months.

Display mode: Exceedance thresholds show days meeting or exceeding a selected amount. Rainfall ranges show mutually exclusive daily-total bins derived from those cumulative thresholds (for example, 1–<2 inches equals the ≥1-inch count minus the ≥2-inch count).

Map style: Grid points display the native ~5-km grid centers directly. Shaded contours create a smoothed visual surface from those same grid-cell values and draw contour lines on top. The contour view is for seeing broad spatial structure; hover values still come from the original grid cells.

Comparison maps show the change in days per year: newer period minus older period. Positive values mean days in the selected threshold/range became more frequent; negative values mean they became less frequent. Percent change is shown in the hover tooltip when the older-period frequency is nonzero.

The era slices are 2005–2025, 1985–2005, and 1965–1985. Those labels are inclusive, so adjacent eras intentionally share the boundary year exactly as specified.

Do not over-interpret tiny pixel differences. nClimGrid-Daily is an interpolated climate analysis derived from GHCN-Daily observations. NCEI notes uncertainty at individual points and days from station density, local variability, observation time, and interpolation. Broad, coherent spatial patterns are more trustworthy than one isolated pixel.

The map intentionally uses complete calendar years only, avoiding a partial current year in the climatology.
