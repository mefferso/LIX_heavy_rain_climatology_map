How this map is built

Methodology & caveats

The analysis counts nClimGrid-Daily grid-cell days meeting each precipitation threshold, then divides by the number of complete years in the selected climatological period. Seasonal views use the same method for the selected calendar months.

Do not over-interpret tiny pixel differences. nClimGrid-Daily is an interpolated climate analysis derived from GHCN-Daily observations. NCEI specifically notes uncertainty at individual points and days from station density, local variability, observation time, and interpolation. Broad, coherent maxima are more trustworthy than one isolated pixel.

The “local hot spots” list ranks the selected frequency field while requiring at least 15 miles between listed points. It is a simple spatial-separation filter, not a formal statistical cluster analysis.

The map intentionally uses the latest complete calendar year, avoiding a partial current year in the climatology.
